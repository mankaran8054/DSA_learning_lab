    Data Structures Playground

    Interact with Stack, Queue, and Linked List. Every operation updates the visualization immediately.

    Stack

    A Stack is a LIFO structure — Last In, First Out. Think of a stack of trays in a cafeteria: you always place and remove from the top.

    Push adds to the top. Pop removes from the top. You cannot access the bottom without removing elements above it.

    Queue

    A Queue is a FIFO structure — First In, First Out. Think of a queue at a ticket counter: the person who arrived first is served first.

    Enqueue adds to the rear. Dequeue removes from the front.
    Value
    Queue is empty. Enter a value and enqueue.
    Size: 0  /  Capacity: 10
    Queue — front to rear
    Queue is empty

    Linked List

    A singly linked list is a chain of nodes. Each node holds a value and a pointer to the next node. Unlike arrays, there is no fixed size and insertion/deletion is O(1) at known positions.

    Traversal always starts from the HEAD.
